# 智枢 Agent(NovaCampus)实施计划 v1.1

> v1.0(2026-09-25)初版计划 → v1.1(2026-09-26)评审修订版。
> 修订原则:**8 周内先做出"简历可用"的最小闭环**,之后再逐层加深;所有事实性假设已在 v0.8.2 源码中逐一验证。

## 一、v1.0 事实核查结果(2026-09-26,基于 v0.8.2 源码)

| v1.0 假设 | 核查结论 |
|-----------|----------|
| WeKnora v0.8.2 存在 | ✅ 存在,且是最新 tag(2026-09-24 发布),锁它 = 锁最新 |
| RBAC 三角色映射 | ✅ 实际为四级:`owner(40) / admin(30) / contributor(20) / viewer(10)`。映射方案成立:校管理员→admin、辅导员→contributor、学生→viewer(owner 仅留给系统自身/演示超管) |
| MCP 扩展路径 | ✅ 但有坑:WeKnora 作为 **MCP Client** 调用外部工具(`discover_mcp_tools`/`call_mcp_tool`),自研 AIOps/周报 MCP Server 走这条路可行;**自带的 Python `mcp-server/` 在 v0.8.2 已弃用**(被内置 Go 版 MCP Server 取代),不要把它当扩展起点 |
| Langfuse 可观测 | ✅ 默认 compose 栈自带 langfuse-web / langfuse-worker |
| ReAct Agent | ✅ 支持,且检索工具已整合为 `search_knowledge` / `read_document` / `list_documents` |
| 模型厂商 | ✅ 内置 27 家,DeepSeek / 智谱 / SiliconFlow(硅基流动)都在 |
| Lite 降级模式 | ⚠️ 需修正:v0.8.x 的 "Lite" 主要指 macOS 桌面版宿主沙箱;Docker 侧轻量配置见根目录 `.env.lite.example` + `deploy/weknora-lite.service`。降级路径存在但要按这两个文件实测,别按"SQLite 单二进制"的旧印象规划 |
| 计划外发现(利好) | ① 官方原生支持 IM 渠道(企业微信/飞书/QQBot/钉钉)与网站嵌入 Widget——"外部渠道"不必模拟,直接用官方能力,省工时且多一条简历素材;② 沙箱(sandbox)服务默认不启动(profile 隔离),对本项目无负担;③ 默认栈 = frontend + app + docreader + postgres(pgvector) + redis + searxng + langfuse,16GB 内存本机可跑 |

## 二、v1.1 相比 v1.0 的修改点

> **v1.2 修订(2026-09-27):架构路线调整——自研 NovaAgent,WeKnora 转为参考与评测基线。**
> 决策原因:用户希望在简历上呈现更多原创工程(自研检索链路/RBAC/Agent 编排),而非在开源平台内做配置与扩展。
> 影响与对冲:① 检索/问答能力自建(SQLite+内存向量、bge-m3 嵌入、RRF 混合、bge-reranker 重排),WeKnora 保留运行作为**同语料对比基线**——"自研 vs 开源底座"评测对比成为 P2 新亮点;② 周报 MCP Server 不依赖平台,由 NovaAgent 以 MCP Client 直连复用(已验证);③ M1 前端校园化(主题/登录页)改为 NovaAgent 自带 UI(模拟统一认证登录页已内建);④ 新增技术债清单:向量库 sqlite→sqlite-vec/pgvector、关键词 LIKE→FTS5/BM25、会话持久化、流式输出。

1. **【最重要】MVP 纵切片前置**:原计划要到 M5(第 22~24 周)才有完整可演示版本,中断风险大、求职窗口不等。改为第 8 周末产出"最小可演示闭环"(见 P1),此后每个阶段结束都保持"可演示状态"。
2. **评测习惯前移**:原 M2 第 7 周才开始。改为从部署当天起维护 bad case 清单,评测集 20 条起步随语料滚动扩充。
3. **评测集新增权限边界用例**:学生角色询问仅管理员可见内容 → 应拒答或降权回答。把 RBAC 和评测串起来,"企业级"才有可量化的证据。
4. **M3 范围裁剪**:模拟系统 3 → 2(教务 + 一卡通;一卡通是故障叙事主角),故障类型先做 2 种(连接池耗尽、CPU 飙高),Grafana 只做一张总览大屏。
5. **服务器策略修正**:≤30 元/月(约 2C2G)跑不动全栈。改为 M5 时只部署精简版(WeKnora 默认栈 + 1 个模拟系统 + MCP),AIOps 全栈本地运行、以录屏交付;服务器到 M5 再买,预算上浮至 40~60 元/月或按量付费。
6. **数据脱敏流程化**:入库前统一跑脱敏脚本(姓名/学号/联系方式),政策文档记录来源 URL + 抓取时间,公开发布前执行自查清单。
7. **(可选加分)真实用户反馈**:P1 结束后找 3~5 名同学/辅导员同事试用,收集 ≥10 条反馈并完成 1 轮迭代——补齐"用户调研→迭代"的 PM 叙事,成本约半天。

## 三、修订后里程碑(2026-09-26 起算)

- [ ] WSL2 + Docker Desktop 安装(管理员权限 + 重启),配置 Docker Hub 镜像加速
- [ ] `docker compose up -d` 拉起默认栈;`cp .env.example .env` 配置 DeepSeek/GLM + 硅基流动 embedding
- [ ] 导入 10 篇真实政策文档

- [ ] 前端校园化:主题/Logo + 模拟统一身份认证登录页(在 weknora/ 内建 `nova-campus` 分支做 Go/Vue 定制)

- [ ] 评测集 v1(≥20 条,含权限边界与拒答用例)+ bad case 清单机制
- [ ] 3~5 人试用 + 1 轮迭代(可选)
- **验收:三角色各视角功能正确;一条周报工作流端到端跑通;录屏 demo 存档**

### P2 评测体系与 RAG 优化(第 9~13 周,至 12-26)★简历第一亮点
