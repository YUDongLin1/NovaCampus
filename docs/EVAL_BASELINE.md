## 二、指标口径

- **Recall@k**(qa 用例):`expect_sources`(标题子串,标注于 cases.json)在返回 sources 标题中的命中比例,k=返回条数(≤5)。均值仅统计带标注的 qa。
- **忠实度**(qa 用例):LLM-as-judge——将 `answer` 与 `sources[].content` 拼接的上下文交由评审模型(复用 NovaAgent 的 qwen-flash 配置,`evals/faithfulness.py`,只读导入不改 novaagent),判"每个事实性陈述是否被上下文支持",0~1。LLM 不可用时降级为词面覆盖率 proxy 并在报告中标注 `faithfulness_method=proxy`(proxy 分数系统性偏低,不可与 llm 分数直接比较)。
- **拒答准确率**(refusal 用例):知识库外问题正确拒答的比例。
- 忠实度不适用于 refusal(正确拒答不扣分)与 permission_api。

## 三、已知注记(基线有效性)

1. **qa-08 回归(open,记录于 badcases.json)**:"休学期满怎么申请复学?"在 21 篇小语料时代通过;75 篇语料后教育部令第 41 号与 EVAL 种子竞争检索,答案未含"休学期满前一周"时限。修复候选(rerank 相关性权重 / 来源去重 / 提示词"优先最相关文件")均涉 `novaagent/**`,待 Qoder 批准后另行任务。
2. **qa-03 R@k=0.0 但通过**:"最长学习年限"的"六年"在多份语料出现(教育部令 41 号等),回答正确但未引用 EVAL 种子——属 `expect_sources` 标注需随语料扩充更新,非质量回归。
3. **LLM-judge 方差**:忠实度均值两次运行分别为 1.0 与 0.8846(temperature=0 仍有轻微波动)。正式对比建议同配置连跑 3 次取中位数;T5 看板聚合多份报告即可自然平滑。
4. **proxy 忠实度不可比**:proxy(词面覆盖率)系统性偏低(实测 0.17~0.98),仅作 LLM 不可用时的降级信号,不计入基线。
