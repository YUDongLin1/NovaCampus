## 2. 改法（判据侧，约 10 行，零额度）

1. **派生时过滤噪声**：只保留「**纯中文、≥4 字**、且含 `无 / 未 / 暂无 / 无法 / 未能 / 不足以 / 建议 / 缺口`
   之一」的片段；含数字、`http`、URL 残片、纯标点残片一律丢弃。
   ⚠️ 过滤规则本身要写成**一个具名纯函数**（如 `_acceptable_no_evidence_frag(frag) -> bool`），
   不要散在派生循环里 —— 这样它能被单独测。
2. **补同义承认无据**：`未细化 / 未覆盖 / 未列明 / 未作规定 / 未规定 / 未提及` 进豁免集。
   但**必须**以「显式常量 + 一条断言它仍在 `refusal.py` 或本文件权威常量里」的方式落地，
   不许凭印象散在判据分支里（坑 45 的根因是两份权威实现互相冒充，不是"不能有第二份词表"）。
3. **三条新的能判红的反向自测**（进 `test_p4f_persona_eval.py`，与现有 A–G 并列）：
   - 断言 + URL、**无**动作词 → **必须判红**；
   - 断言 + 含小数、**无**动作词 → **必须判红**；
   - 「库内未细化…办理流程」→ **必须判绿**；
   并且**断言派生集合里不存在任何含数字或 `http` 的片段**（一条静态体检，防止将来模板一改又漏进来）。
