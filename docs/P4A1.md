## 一、判据(C1)

`main.py` 新增两个纯函数,`quality_gate_reject` 在登录页特征检查之后调用:

```python
index_page_stats(text)   # 逐非空行统计:
#   短行 = len(行) ≤ 12 且不含 、，。：；！？ 且不含数字   (纯菜单项)
#   长行 = len(行) > 25 且含上述句读                      (正文式句子)
is_index_page(text)      # total_lines ≥ 20 且 short_ratio ≥ 50% 且 long_ratio < 15% → 命中
```

命中 → 拒绝 `{code: "index_page", reason: "导航/索引型页面:菜单式短行占比 NN%(x/y 行),正文式长行仅 MM%", hint: "请粘贴具体文章页 URL（含发布日期/正文的页面），导航页无法入库"}`。

**判据调整与理由(规格允许调整,须说明)**:
1. 增加 `total_lines ≥ 20` 的**小样本护栏**——规格判据是纯比例,极短文本(如 4 行便签)会因比例偶然命中;
   导航页特征就是"行数多且大多是菜单",20 行护栏不影响真实目标。
2. 实测样本 81 行(去注释头)/短行 **61.73%**/长行 **9 条**→ 被拒,与 Qoder Review 分析(62%/9 条)一致;
   实站抓取(经 main.py extract_html+clean_body)为 68 行/短行 57%/长行 12% → 同样被拒(两口径均稳健)。
